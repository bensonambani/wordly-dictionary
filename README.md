# Wordly – English Dictionary SPA

## Project Description
Wordly is a Single Page Application (SPA) that allows users to search for English words and view their meanings, pronunciation, examples, and synonyms.

## Features
- Search for English words.
- View word definitions.
- View pronunciation.
- Play audio pronunciation when available.
- Save favorite words.
- Dark mode and light mode.
- Display an error message for words that cannot be found.

## Technologies Used
- HTML
- CSS
- JavaScript
- Free Dictionary API

## API Used
https://api.dictionaryapi.dev/api/v2/entries/en/

## How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter an English word in the search box.
5. Click Search to view its information.
